Sobre el proyecto

AURA-IA es un prototipo académico que utiliza datos simulados para mostrar cómo pueden identificarse diferencias en los resultados de un sistema de inteligencia artificial entre distintos grupos.

El proyecto no diagnostica enfermedades, no recomienda tratamientos y no sustituye la valoración del personal médico.

Integración de las materias

Física

La Física se utiliza para explicar cómo el movimiento y las vibraciones durante una captura pueden afectar la nitidez y calidad de una imagen.

En AURA-IA este concepto se relaciona con las condiciones de captura, especialmente cuando se plantea el uso de unidades móviles.

La idea principal es sencilla: si existe movimiento durante la captura, la imagen puede perder nitidez.

Matemáticas Discretas

Las Matemáticas Discretas permiten representar las decisiones del prototipo mediante valores de verdadero y falso, tablas de verdad y operaciones lógicas.

AURA-IA utiliza principalmente:

  • NOT: significa NO.
  • AND: significa Y.
  • OR: significa O.

Estas operaciones permiten construir una regla que determina cuándo un registro debe pasar a revisión humana.

Los valores también pueden representarse de manera sencilla: 1 significa verdadero o sí y 0 significa falso o no.

Cálculo Diferencial

El Cálculo Diferencial se utiliza para observar cómo cambia un resultado cuando modificamos un valor.

En AURA-IA se aplica para explicar cómo puede cambiar el resultado del análisis cuando se modifica el umbral de alerta.

La derivada se interpreta de manera sencilla como una medida de qué tan rápido cambia un resultado.

En palabras sencillas, el cálculo nos ayuda a responder: si cambiamos el umbral, ¿qué tanto cambia el resultado?

Geometría Analítica

La Geometría Analítica permite ubicar puntos y zonas dentro de las imágenes mediante coordenadas.

En AURA-IA se utilizan conceptos como:

  • Eje X y eje Y.
  • Coordenadas.
  • Distancia entre dos puntos.
  • Línea recta.
  • Punto medio.
  • Parábola.

Estas herramientas ayudan a representar y medir zonas de interés dentro de las imágenes de prueba.

Por ejemplo, las coordenadas pueden utilizarse para señalar una zona dentro de una imagen de piel o de tórax, mientras que la distancia entre puntos puede utilizarse para representar de manera aproximada el tamaño o separación de una región seleccionada.

La parábola se utiliza únicamente como ejemplo matemático para representar una curva o contorno. Estas herramientas no diagnostican melanoma ni cáncer de pulmón.

Programación

La Programación permite unir las diferentes partes del proyecto.

AURA-IA utiliza Python para organizar los registros, procesar los datos simulados y calcular los resultados del prototipo.

El programa puede organizar los casos por género y región, calcular falsos negativos y obtener la tasa de falsos negativos.

También permite presentar los resultados mediante tablas y gráficas y mostrar una alerta cuando se encuentra una diferencia que requiere revisión.

Perspectiva de género e interseccionalidad

La perspectiva de género permite comparar si los resultados son diferentes entre los grupos utilizados en la demostración.

La interseccionalidad permite observar más de una característica al mismo tiempo.

Por esta razón, en la demostración académica se comparan:

  • Mujer - Urbana.
  • Mujer - Rural.
  • Hombre - Urbana.
  • Hombre - Rural.

El propósito es demostrar que un buen resultado general puede ocultar diferencias entre grupos y que esas diferencias deben revisarse antes de obtener conclusiones.

Abreviaturas utilizadas

IA: Inteligencia Artificial.

CSV: valores separados por comas. Es un formato utilizado para guardar información organizada en filas y columnas.

FN: falsos negativos. Son casos realmente positivos que el sistema identifica incorrectamente como negativos.

FNR: tasa de falsos negativos. Indica qué porcentaje de los casos positivos reales fue clasificado incorrectamente como negativo.

pp: puntos porcentuales. Se utiliza para expresar la diferencia entre dos porcentajes.
